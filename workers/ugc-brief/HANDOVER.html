Share Your Brief: handover

Worker ugc-brief on ugc.tahastudiolabs.com. One hub for the brief, hook and script approval, delivery and revisions. Folder: workers/ugc-brief.

What it does

  • /brief/ intake form, then each client's private dashboard (link emailed once, from hej@tahastudiolabs.com).
  • /brief/studio hidden studio for you. Magic link sign-in, only for addresses in ADMIN_EMAILS. No public page links to it.
  • Production stays locked until the client approves one hook and confirms the script (enforced on the server).
  • Two included change rounds before production (you can add an extra round). 7 day revision window after delivery, limited by package.
  • Brief alert with all answers goes to hej@tahastudiolabs.com. Client emails carry only a link. Other client emails go out only when you tick "Notify client".
  • Em dashes are stripped from everything saved or sent.

Deploy (after you approve the staging preview)

cd workers/ugc-brief
npm install
npx wrangler d1 create ugc-brief-db        (put the printed id into wrangler.json)
npx wrangler r2 bucket create ugc-brief-files --jurisdiction eu
npx wrangler secret put LINK_SECRET         (any long random string)
npx wrangler secret put RESEND_API_KEY      (same key as brain-vault)
npx wrangler deploy

Local test

copy .dev.vars.example to .dev.vars
npm test

Assumptions to confirm

  • Revision rounds per package (src/config.js): Starter 1, Growth 2, Scale 2, Retainer 3 (priority). Your brief did not say which package gets which.
  • The live site shows "Single video" and "Content pack"; the brief and this dashboard use Starter, Growth, Scale, Retainer.
  • Files over 95 MB: paste a delivery link instead.
